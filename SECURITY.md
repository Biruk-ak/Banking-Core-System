# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a vulnerability

If you discover a security issue in Banking Core System (especially around auth, ledger, payments, fraud, AML, or KYC), please email **birukaklilu0110@gmail.com** instead of opening a public issue.

Include:

- Description and impact
- Steps to reproduce
- Affected commit / branch if known

We aim to acknowledge reports within 72 hours.
